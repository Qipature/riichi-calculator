# 雀点 · 日麻线下工具箱 🀄

适合线下四人日本立直麻将，尤其适合熟悉四川麻将、刚接触日麻的玩家。

**在线地址：** https://qipature.github.io/riichi-calculator/

## 功能

- **番符计算器**：按役种选择或直接输入番符；荣和、自摸、庄闲、本场、立直供托；宝牌、赤宝牌、里宝牌；刻杠、雀头、听牌符；满贯至役满。发现常见规则冲突时暂停结算。
- **向听数分析**：录入13或14张门清手牌，计算普通型、七对子、国士无双向听数；13张提示有效进张，14张提示可考虑的舍牌。
- **规则教程**：面向川麻玩家，含开局、吃碰杠、立直、役、振听、流局和点数结算。
- **役种图鉴**：常见一般役、役满、番数与副露变化。
- **点数速查表**：按庄闲、自摸/荣和查1～4番点数。
- **开门定位器**：支持直接选择两骰总点数2～12、分别输入两颗骰子、随机掷骰；自动给出东南西北哪家牌墙及从右数第几墩开门，并用17墩牌山和座位图显示开门位置、王牌及跨墙提示。
- **牌桌工具**：开局检查清单、和牌检查表。
- **手机适配与离线**：纯原生HTML/CSS/JS；首次成功访问并由支持Service Worker的浏览器缓存后可离线。

## 部署

本项目为纯静态网站。GitHub仓库 **Settings → Pages → Deploy from a branch → main / (root)**。不需要Node、npm或数据库。仓库中的 `index.html` 即为完整网页，`sw.js` 是离线缓存，`manifest.webmanifest` 支持添加至主屏幕。

## 使用范围及限制

- 番符计算器要求玩家**自行判断役种已成立**；它不是从14张牌自动解析所有役种、振听及和牌合法性的完整引擎。
- 向听分析只面向**13/14张未副露手牌**，不处理吃碰后余牌不足13张、可见牌及振听。
- 役满复合、双倍役满、食断、切上满贯、累计役满等存在规则差异；责任支付、多家荣和、复杂流局及其他地方规则需人工约定处理。
- 计算结果的警告是常见冲突检查，不能证明多个役种一定能在同一真实牌姿中成立。
- 本场：荣和每本场+300点，自摸每位支付者每本场+100点；桌上的立直供托作为和牌方额外收入，不增加对方即时支付。
- 仅作为线下学习和辅助结算工具。

## 开发维护

- 修改 `index.html` 即可改变界面及计算逻辑。
- 更改网页后更新 `sw.js` 中的缓存版本号，避免离线残留旧版。
- 开门定位器使用**常见单次掷两骰**开墙规则：庄家作为第1家，按东南西北逆时针数座位；在指定牌墙右端数同点数墩数，并在第N与第N+1墩之间开门。双次掷骰等变体需另行约定。
- 无个人数据上传。请在同一局中事先统一规则。
